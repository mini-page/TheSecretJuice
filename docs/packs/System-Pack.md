# ⚡ System Pack

Comprehensive system maintenance, optimization, and hardware information steroids.

**Folder:** `Steroids/Sys/`

## 🛠️ Included Modules

### 1. `Sys-Maintanance.ps1`
- **Command:** `optimize`
- **Features:** Comprehensive system cleanup, service optimization, memory management, and network tuning.
- **Usage:** `optimize [-Preview] [-Quick]`

### 2. `Sys-Info.ps1`
- **Command:** `sys-info`
- **Features:** Detailed hardware and OS snapshot, including CPU, RAM, Disk, and GPU details.
- **Usage:** `sys-info [-Quick] [-Export path]`

### 3. `Clean-OldFiles.ps1`
- **Command:** `clean-files`
- **Features:** Scan and remove temporary files, old logs, and cache across common system directories.
- **Usage:** `clean-files`

### 4. `Restart-specs.ps1`
- **Command:** `restart-specs`
- **Features:** Quickly view machine specifications while initiating a terminal restart.
- **Usage:** `restart-specs`
