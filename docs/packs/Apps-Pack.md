# 📦 Apps Pack

Software management and multi-source update tracking steroids.

**Folder:** `Steroids/App/`

## 🛠️ Included Modules

### 1. `Update-Apps.ps1`
- **Command:** `update-apps`
- **Features:** Universal updater for Winget, Scoop, and Chocolatey. Update all your apps with one command.
- **Usage:** `update-apps [-winget] [-scoop] [-choco] [-AutoYes]`

### 2. `Get-AppsInfo.ps1`
- **Command:** `get-apps`
- **Features:** List installed applications from all package managers and the Windows registry.
- **Usage:** `get-apps [-Source All|Winget|Scoop] [-Export path]`
