# ⚙️ Core Essentials

Foundational helpers, profile management, and master help system.

**Folder:** `Steroids/Core/`

## 🛠️ Included Modules

### 1. `Profile-Management.ps1`
- **Command:** `profile`
- **Features:** Edit, backup, compare, and reload your PowerShell profile with ease.
- **Usage:** `profile [-Action Reload|Edit|Backup]`

### 2. `Help-Summary.ps1`
- **Command:** `juice-help`
- **Features:** The master help directory for all loaded Secret Juice modules.
- **Usage:** `juice-help [tool]`

### 3. `Juice-Helpers.ps1`
- **Module:** Internal Helpers
- **Features:** Provides shared UI functions (`Write-JuiceBanner`, `Write-Color`) to keep the ecosystem consistent.
