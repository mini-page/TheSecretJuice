# 🛠️ Dev Pack

Developer-focused steroids for tool discovery, manual access, and shell analytics.

**Folder:** `Steroids/Dev/`

## 🛠️ Included Modules

### 1. `Dev-ToolsInfo.ps1`
- **Command:** `tools-info`
- **Features:** Scan and report versions/status of common development tools (Node, Python, Go, Rust, etc.).
- **Usage:** `tools-info [-Check tool1,tool2]`

### 2. `Man-Pwsh.ps1`
- **Command:** `man-pwsh`
- **Features:** Beautifully formatted, colored manual pages for PowerShell cmdlets.
- **Usage:** `man-pwsh <cmdlet-name>`

### 3. `Z-Statistics.ps1`
- **Command:** `z-stats`
- **Features:** Analyze your PowerShell usage patterns, most frequent commands, and session duration.
- **Usage:** `z-stats`
